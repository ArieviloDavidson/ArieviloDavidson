## 🇧🇷 Sobre Mim

Sou **Engenheiro e Analista de Dados** com sólida formação em **Engenharia de Computação (UERJ)** e atuação prática na convergência entre Engenharia de Software, Cloud e Inteligência de Negócios.

- 🚦 **Setor de Mobilidade**: Atualmente atuo no setor de mobilidade, desenvolvendo soluções de dados para otimização de fluxos, análise de métricas operacionais e suporte a decisões estratégicas data-driven.
- 🏗️ **System Design, Cloud & Open Source**: Além de experiência avançada em **Google Cloud Platform (GCP)** (BigQuery, Cloud Composer, Dataflow, Dataplex), projeto e implemento arquiteturas escaláveis com ferramentas open-source de alta performance, como **ClickHouse** (analítica colunar ultra-rápida), **Apache Superset** (BI e exploração moderna) e **Apache Airflow** (orquestração robusta de pipelines).
- ⚡ **Automação & Gestão do Conhecimento**: Criação de fluxos e integrações automatizadas via **n8n** e organização de bases de conhecimento estruturadas com **Obsidian**.
- 💻 **Desenvolvimento Web (Front-End & Full Stack)**: Paralelamente à área de dados, desenvolvo aplicações web modernas em **React** e **Next.js**, incluindo **websites institucionais, blogs, plataformas para cursos e portais para eventos**.

## 🇺🇸 About Me

I am a **Data Engineer & Data Analyst** with a degree track in **Computer Engineering (UERJ)**, working at the intersection of Software Engineering, Cloud Architecture, and Business Intelligence.

- 🚦 **Mobility Sector**: Currently operating in the mobility sector, engineering data solutions that streamline operations, process telemetry/logistics metrics, and empower data-driven decision-making.
- 🏗️ **System Design, Cloud & Open Source**: In addition to extensive **Google Cloud Platform (GCP)** expertise (BigQuery, Cloud Composer, Dataflow, Dataplex), I design and deploy scalable architectures using cutting-edge open-source and cloud technologies, including **ClickHouse** (ultra-fast columnar analytical storage), **Apache Superset** (modern data exploration and BI), and **Apache Airflow** (resilient pipeline orchestration).
- ⚡ **Automation & Knowledge Management**: Designing automated workflows and API integrations via **n8n**, combined with structured personal knowledge management (PKM) in **Obsidian**.
- 💻 **Web Development (Front-End & Full Stack)**: Alongside data engineering, I build modern web applications using **React** and **Next.js** — delivering high-converting **company websites, blogs, educational course platforms, and event portals**.
